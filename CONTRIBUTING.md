# Contributing

Use `npm ci`, `npm test` and `npm run build`. For UI changes, install Chromium with `npx playwright install chromium` and run `npm run test:browser`.

Keep changes focused. Preserve project/session boundaries, optimistic version checks, and user ownership of the current tree. Add both English and Chinese UI strings. Use fictional fixtures; do not commit conversations, local data, generated client configuration, credentials, or personal machine paths.

Describe the user-visible problem, changes, and validation in pull requests. Contributions are provided under this repository's MIT license.
